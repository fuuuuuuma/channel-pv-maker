# 軽い質問の作り方（下調べの後に 1 回だけ）

質問は「白紙で聞く」のではなく、**下調べから作った案を見せて選んでもらう**。利用者は映像の素人とは限らないが、
長い問診は嫌がる。1 回で済ませ、2 回目は構成表の承認だけにする。

## 下調べで押さえておくこと（質問の前）

- チャンネルの主題と出演者（誰が何回出ているか・オーナーは誰か）
- 強い発言の候補 10〜20 個（文字起こしから。痛み・転機・理念・実績・誘いの言葉）
- 数字の実績（会員数・開催回数・再生数など。出典の動画か投稿を控える）
- 使えそうな絵（イベントの集合写真・現場・笑顔）と、焼き込みの字幕やラベルの位置（`sheets` の一覧で見る）
- ロゴ・アイコン・バナー（`assets/brand/` に入る）。無ければ質問で「ロゴの画像はありますか」と聞く

## 聞くこと（この 6 つ。既定値を付けて、選ぶだけで答えられるようにする）

1. **目的と見る人** — 例：「チャンネルの紹介（初めて見る人向け）」「コミュニティの入会を考えている人向け」「イベント・募集の予告」。
   下調べから一番近いものを（おすすめ）にする。
2. **長さ** — 1 分／2〜3 分（おすすめ）／4〜5 分。素材が多ければ長めでよいと言われやすい。
3. **構成の案** — 下の 3 つの型から下調べに合わせて 2〜3 案を作り、実際の発言を入れて見せる（`structure.md`）。
   - 痛み→転機→世界→中身→声→想い→誘い（コミュニティ・スクール向き）
   - 実績で掴む→人→中身→声→誘い（実績の数字が強いとき）
   - ドキュメンタリー（1 人の歩み→仲間→これから）（オーナーの語りが長く撮れているとき）
4. **見た目の案** — `design.md` の 2 つの型を、ブランドの色に合わせて言葉と色で短く。例：
   - A シネマ（黒基調・上下の黒帯・差し色 1 色・縦書きの明朝の強調。CM 寄り）（おすすめ）
   - B ブランド色（黒帯なし・題字と終わりはロゴの色の地とポップなキャッチ。親しみ寄り）
   どちらも題字と終わりはロゴの画像を使える。迷っているなら「見本を 2 枚作って見せます」と言い、
   `still` で場面と強調を 1 コマずつ作って見せてよい。
5. **必ず入れる人・言葉・最後の一言／入れないもの** — 「最後はオーナーの〇〇さんの『〜』で締めますか」のように案を添える。
6. **素材と費用** — 「チャンネルの映像・X の投稿・バナーは使ってよいですか（持ち主の許可）」「AI で冒頭の演出を作る・BGM や効果音を
   生成する場合、上限いくらまで使ってよいですか（使わない、も可）」。After Effects の有無は doctor で分かるので聞かない。

## 聞き方の例（Claude Code の選択式の質問）

```
質問1「目的」: [コミュニティの入会を考えている人向け（おすすめ）] [チャンネルを初めて見る人向け] [イベント・募集の予告]
質問2「構成」: [A 痛み→転機→世界→中身→声→誘い（おすすめ）] [B 実績で掴む] [C オーナーのドキュメンタリー]
   （各案の説明に、冒頭と締めに使う実際の発言を 1 つずつ書く）
質問3「見た目」: [A シネマ（おすすめ）] [B ブランド色]
質問4「長さと費用」: [3分・有料生成なし（おすすめ）] [5分・AI 動画も使う（上限を聞く）] [1分]
```
自由記述（入れたい人・言葉・NG）は「その他」に書いてもらう。Codex では同じ内容を番号つきで本文に出す。

## 返事をもらったら

- 構成表（`planning/plan.md`）を作り、**表のまま**見せて承認をもらう。列：幕／秒（目安）／話者／動画 ID と秒／字幕（区切り）／強調／絵（同期か差し込み）／場面。
- 承認の後に増えた要望（「この人も入れて」）は構成表を直して見せ直す。組み立てが進んだ後の大きな変更は、何を作り直すかを先に伝える。
