# 検品

「書き出せた」と「良い」は別。次を全部やってから報告する。

## 機械の検査（`qa`）

- 音量は -14 LUFS 前後・ピーク -1 dBFS 以下（mix が合わせる）
- 明るさの跳ね（1〜2 コマだけ明るい・暗い）＝ 0 件
- 0.3 秒未満の真っ黒が出たら、その時刻の一覧を見る（暗転の手前が硬く切れていないか）
- `build/_qa/voices.txt`：声だけを発言ごとに区切って起こしたもの。字幕の区切りと比べ、頭に前の言葉・終わりに次の言葉が混ざっていないか、
  語尾が欠けていないか。混ざっていたら edl.py の a・b（か audio.json の `force_end`）を直す

- 読み切れないかもしれない文字：字幕・名前の札・強調の出ている長さを文字数と比べ、短すぎる順に出す（`build/_qa/texts.json`）。
  字幕と強調は声と一緒なので 1 秒 10 字、名前の札は声が無いので 1 秒 5 字・最短 1 秒が目安。出たら edl.py の名前の札の秒・sub の区切りを直す

## 目で見る（全部）

- `build/_ae_check/sheet.jpg`（AE）か `build/_ff_check/sheet.jpg`（ffmpeg）：見た目の全体
- `build/_qa/cuts_*.jpg`：全カットの頭・中・終わり（1 行に 2 カット。左上に番号・時刻・長さ。0.3 秒未満は赤い SHORT）
- `build/_qa/cut_*.jpg`：全切り替え・寄り・名前・強調の前後 ±0.25 秒（8 列×2 段、左上の赤い数字がその秒）
- `build/_qa/montage_*.jpg`：高速の連打の全コマ
- `build/_qa/fast_*.jpg`：連打以外で動きの速い所の前後 1 秒の全コマ

もっと細かく見るときは見る道具を使う：`python3 "$PV" look strip <動画> 61.0 62.5`（その区間の全コマ）、
`python3 "$PV" look crop <動画> 61.2 600,300,640,360 --zoom 2`（原寸の切り抜き）。出力は動画の隣の `look/`。

サブエージェントが使えるなら、cut_*.jpg の検品を任せてよい（数十枚あり時間がかかる）。頼み方の雛形：

```
あなたは動画の検品役です。ファイルは読むだけ。対象: <案件>/build/_qa/cut_*.jpg と montage_*.jpg
前提: 上下に黒帯のある紹介 PV。字幕は下の黒帯の中の白文字。黒への暗転・ディゾルブ・縦書きの強調（入りの帯状のずれ）・顔への素早い寄りは意図した演出。
探すもの: 1) 切れ端（前後どちらとも違う場面が 1〜3 コマ挟まる） 2) 元動画の焼き込み（色付きの字幕・吹き出し・章ラベル・話者アイコン）
3) 一瞬の白い閃光・意図しない黒 4) 文字の重なり・はみ出し 5) 顔が黒帯や文字で隠れる
出力: 問題の一覧（ファイル名 / 秒 / 種類 / 見えたもの）と「問題なし: N 枚」。確信が低いものは「要確認」。
```

返ってきた指摘は**自分で拡大して確かめてから**直す（`ffmpeg -ss 秒 -i 動画 -frames:v 1 -vf crop=...`）。勘違いもある。

## 直し方の早見

| 見えたもの | 直す所 |
|---|---|
| 切れ端 | edl.py の a を後ろへ・絵の始めを遅らせる・`hard=True` → `prep` 以降 |
| 焼き込み | framing.json の倍率を上げる・上下にずらす／差し込みを替える／連打から外す → `plan` 以降 |
| 顔が切れる・隠れる | framing.json／強調の `layout`／`punch=dict(face=...)` → `plan` 以降（強調は `telops` も） |
| 語尾が欠ける・次の言葉が入る | edl.py の b／audio.json の `force_end` → `prep`（語）→ `mix` 以降 |
| 字幕の切り替えが早い・遅い | edl.py の sub の区切り → `plan` 以降 |
| 場面の文字のはみ出し | scenes.json → `still` で確かめて `scenes` 以降 |

直したら書き出し直し、直した所の一覧をもう一度見る。報告では「直した所・確かめた方法」を書く。
