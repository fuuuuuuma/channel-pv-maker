# 素材を足す（音楽・効果音・AI 動画・X の投稿・バナー）

お金や外部サービスが絡むものは、**何を・何本・いくらかを見積もってから**利用者の承認をもらう。承認は 1 回ごと。上限を超えそうなら止まって聞く。

## 音楽と効果音

- 一番よいのは利用者が持っている曲（ライセンスのある BGM）。`assets/music/` に置いてもらう。
- 無いときの選択肢：フリーの BGM サイト（規約を読んで、商用と動画内の利用が可のものだけ）／音楽生成 API（ElevenLabs Music など。有料・承認）。
- 曲は幕ごとに入れ替える：冒頭は静か（痛み）→ 転機で頭打ちから明るい曲 → 中身は手拍子など軽い段 → 声の区間は温かい曲で少し大きく → 締めは加速して終わりの画面で一撃。
  1 曲の中から区間を切り出して使ってよい（audio.json の `from`）。
- 効果音：寄りの風切り（`auto.punch`）、強調の衝撃音（`auto.big`）、場面の動きに合わせた紙・ピン・風。夜の部屋の環境音（雨・PC のファン）は冒頭の余白を埋める。
  どれも小さめ（-12〜-22dB）。音は先に「何秒の何の音を何本」を決めてから作る。
- 効果音は**重低音寄り**に（高い電子音は「ダサい・子どもっぽい」と言われた）。生成した効果音は 6kHz より上を落とすと本編を邪魔しない。
- 依頼主が曲を作り直すときは、場面の時刻と欲しい音（無音・サビ・山場・最後の一撃）の時間表と、曲の長さを渡す。

## AI 動画（任意・有料）

転機の演出に効く：例「暗い部屋で一人編集しているモニターが紙のように破れ、ロゴのキャラクターとオーナーのイラストが飛び出す」。
- 作り方（Higgsfield などの動画生成）：まず静止画で「最初のコマ」（暗い部屋）と「最後のコマ」（破れて飛び出した瞬間。キャラクターやイラストの参照画像を渡す）を作り、
  始めと終わりのコマを指定した動画（5 秒）にする。安いモデルで 2 案 → 良い方を使う。高画質のモデルは高いので、山場の 1 本だけ。
- 実例の費用感：静止画 1 枚 0.25〜3 クレジット、Kling 3.0 pro 5 秒 7.5、Seedance 2.5 1080p 5 秒 60（2026-10 時点。必ず見積もり機能で確かめる）。
- 置き方：`assets/ai/<名前>.mp4` に保存し、edl.py で `ai('tear', 'assets/ai/tear.mp4', 5.0)`。破れる音は audio.json の sfx で、画面が破れる瞬間に合わせる。
- 実在の人物の写実的な顔は作らない（本人のイラストなど、許可のある絵柄で）。

### 1 枚絵に演技させる（Image to Video）

告知の絵（生成した静止画）を「映像として」動かす。やり方と注意は `references/trailer.md` の「1 枚絵を動かす」。
- 実例の費用（2026-10・Seedance 2.5・4 秒・音なし）：480p 下書き 12／**720p 28**／1080p 64 クレジット。720p で作り、手元の Real-ESRGAN で 1080p にすれば十分だった。
  毎回、見積もり機能（get_cost）で確かめる。何本・いくらかを見せて承認をもらう。
- 演技が欲しいカットだけ（例：16 本＋仲間 6 本）。振り返り・見上げは end_image、殴る・飲むは start_image。
- 手元の無料の動画生成（LTX-2.3 の Mac 向け版など）はクレジット 0 で使えるが、顔の保ち方と画質は落ちる。モデルの重みの商用条件は道具のライセンスとは別なので確かめる。

## X の投稿

- 投稿の URL か ID を 1 行ずつ書いたファイルを `xshot` に渡すと、公開の埋め込み表示（ログイン不要）から投稿のカードを PNG にする。
  消された・鍵付きの投稿は取れない（research/xshot.json に理由）。
- 投稿の持ち主（コミュニティの公式・オーナー・メンバー）から使ってよいと言われたものだけ。第三者の宣伝・個人的すぎる内容は外す。
- 使い道：`xwall`（大量に壁へ）・`quotes`（言葉を文字で読ませる）・`stat` の添える画像（数字の出典）。

## バナー・サムネ

- イベントの告知バナーは公式の X やオーナーの X に多い。集め方：検索で投稿を探す → 埋め込み表示の画像（pbs.twimg.com/media/…?name=large）を保存。
  重複・ぼやけ・求人や個人情報の写るもの（Discord の画面など）は外す。
- YouTube のサムネは `harvest` が assets/thumbs に集める。`list`（企画の一覧）・`wall`（バナーの壁）・`stat` の背景に使う。
