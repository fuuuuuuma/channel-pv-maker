# 審査（作っていない目で採点して直す）

自分で作った PV は甘く見える。`qa` の検品で直すことが無くなったら、作っていない担当に厳しく採点させ、その指摘で直し、もう一度採点させる。`qa.md` の切り替えの一覧の検品（切れ端・焼き込みを探す）とは別で、こちらは作品としての出来を点数で見る。

## いつ・誰が

- `qa` の検品と切り替えの一覧の目視で直すことが無くなってから、確認用プレビューを依頼主に見せる前
- 審査役は新しく立てた別の担当。Claude Code はサブエージェント、Codex は別のエージェントか新しい会話。前の版の審査役を使い回さない
- 渡すのは「動画のパス」「構成表（`planning/plan.md`）」「見た目の約束（`build/style.json`・ブランドの色）」「`pv.py look` の使い方」だけ。作った側の苦労や意図は書かない
- 審査役はファイルを読むだけで、直さない

## 頼み方（そのまま使える）

```
あなたは映像の審査員です。この PV は作っていません。テレビ CM・広告に出せる水準に届かせるために、遠慮なく、具体的に審査してください。褒め言葉は要りません。

対象: <案件>/exports/<名前>.mp4
仕様: 1920×1080・<長さ>、構成表 <案件>/planning/plan.md、見た目 <案件>/build/style.json、ブランドの色 <色>
見る道具: python3 <プラグイン>/scripts/pv.py look（cuts / fast / strip / crop / read）。<案件>/build/_qa/ に一覧が出ている

1. 見る（数字だけで決めない）
   - build/_qa/cuts_*.jpg：全カットの頭・中・終わり。cut_*.jpg：切り替えの前後。fast_*.jpg・montage_*.jpg：速い動きと連打の全コマ
   - 山場（強調・題字・終わり）の前後は look strip で全コマ、顔・文字の縁は look crop で原寸
2. 仕様を確かめる：長さ、-14 LUFS 前後・ピーク -1 dBFS 以下、意図しない黒・明るさの跳ねが無い、強調の衝撃音と画が合う
3. 7 つの観点を 1〜10 点で採点する。5＝学生の課題、6＝テンプレート並み、7＝しっかりした仕事、8＝一流の制作会社、9＝広告賞の候補、10＝世界一。最初の書き出しは 5〜7 が普通。甘くしない
   - 発言とつなぎ：文脈が通る所で切れている、切れ端が無い、最後は主役の一言
   - 引き：冒頭の数秒で続きを見たくなる、山場がはっきり 1 つある、締めが冒頭と響き合う
   - 動き：寄り・溶け・連打の速さ、カメラが急でない、同じ動画の繰り返しが無い
   - 文字と構図：字幕・縦書きの強調・名前の札・場面の文字の読みやすさと置き場所、顔を隠さない
   - 仕上げ：色・黒帯・焼き込み・閃光・画質の荒れ
   - 音：声のフェード、音楽の下げ方、効果音、静かな間、音の受け渡し
   - 技術：仕様どおり、書体の欠け（□）が無い、音の割れが無い
4. 直すことを 5〜10 件、効きの大きい順に。各件に「時刻／見えていること／なぜ効くか／どう直すか（edl.py のブロック名・秒・audio.json の値・px など数字で）」。細かい指摘を並べるより、大きな改善を少し。少なくとも 1 件は山場・驚きを上げる直しにする
5. 致命は別に挙げる：テンプレートや AI の定型に見える所、不自然な日本語、代わりの書体・□、仕様違反、許可の無い素材やロゴ、顔の隠れ
6. 耳でしか分からない所（声の聞こえ方・間の気持ちよさ）は「未確認」と書く

返すもの：点数表・致命の一覧・直すことの一覧
```

## 直す（作った担当）

- 今の版を残す。直した版は次の版（v2）として書き出す。上書きしない
- 致命と、効きの大きい直しは全部入れる。もっと良い直し方に自信があれば替えてよい（理由を書く）。審査役が良いと言った所は崩さない
- 直す所は `qa.md` の「直し方の早見」の順でやり直し、書き出し直したら `qa` を流し、直した所を `pv.py look strip` / `crop` で見て本当に直ったか確かめる
- 点数表と、採った直し・見送った直しと理由を `planning/review_<版>.md` に残す（`build/_qa` は `qa` のたびに作り直されるので、そこには置かない）

## 何周回すか

- 目標：全観点 8 点以上・致命 0。審査と直しは 3 周まで
- 届かなかった観点は、点数と理由をそのまま報告の「確認してほしい所」に書く。上がったふりをしない
- 有料の生成（AI 動画・音楽・効果音の作り直し）が要る直しは、見積もりを出して承認を取ってから
